# 🥛 Fresh Meadow Dairy - Web Storefront

Direct-to-consumer digital storefront for Fresh Meadow Dairy. Delivers an organic dairy browsing and ordering experience with cold chain tracking and morning farm-to-door delivery scheduling.

## 🚀 Features
- **Modern Stack:** React 18 with Vite and Tailwind CSS v4.
- **Product Catalog:** Whole milk, Greek yogurt, salted farm butter, artisan cheeses, whipping cream, and fruit yogurts.
- **Cold-Chain Assurance:** Temperature specifications and fresh shelf-life disclosures for every product.
- **Cart & Cold Packaging:** Slide-over cart drawer with automated cold-pack insulation fee calculation.
- **Express Morning Delivery:** Next-morning fresh delivery checkout scheduler with order generation.

## 📦 Scripts
- `yarn dev` - Start Vite storefront development server
- `yarn build` - Compile production bundle to `dist/`
- `yarn preview` - Locally preview production build
