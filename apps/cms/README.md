# 🧀 Fresh Meadow Dairy - CMS Portal

An enterprise-grade administration portal for Fresh Meadow Dairy operations, inventory managers, and fulfillment teams.

## 🚀 Features
- **Modern Stack:** React 18 powered by Vite and Yarn.
- **Tailwind CSS v4:** Fully integrated with custom brand variables, component layers, and theme tokens.
- **Workflow Modals:** React Portal confirmation dialogs for all create, edit, and destructive actions.
- **Operational Modules:** Product catalog, inventory batching & cold storage tracking, categories, orders, settlements, staff administration, and customer records.
- **Branded Authentication:** Split-screen login interface with pastoral background accents.

## 📦 Scripts
- `yarn dev` - Start Vite development server
- `yarn build` - Compile production bundle to `dist/`
- `yarn preview` - Locally preview production build
